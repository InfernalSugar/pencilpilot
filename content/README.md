# Content

Teaching content for PencilPilot. Everything in this folder is licensed
**CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/), separately from the MIT-licensed code.

| Folder | What goes here | Milestone |
|---|---|---|
| `rules/` | Diagnosis rules (TOML): measurement + threshold → mistake | M4 |
| `tips/` | Tip text for each mistake, 2–4 variants, with `{placeholders}` | M4 |
| `lessons/` | Mini-lessons and drills (Markdown) | M6 |
| `references/` | One `manifest.json` per category: source URL, licence, author, keypoints, approval flag. **Image files are never committed.** | M5 |

See `docs/planning/CONTENT_GUIDE.md` for the writing style and `docs/planning/LICENSING.md` for reference-image rules.
